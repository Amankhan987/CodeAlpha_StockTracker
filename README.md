# CodeAlpha_StockTracker

A simple stock portfolio tracker built in Python as part of the CodeAlpha Python Programming Internship.

## Description
The user enters stock names and quantities. The program uses a hardcoded dictionary of prices to calculate the total investment value and saves the result in a text file.

## Features
- Hardcoded stock prices (AAPL, TSLA, GOOGL, MSFT)
- Calculates value of each stock and total investment
- Checks for invalid stock names
- Saves the result in portfolio.txt

## How to Run
1. Install Python
2. Download `stock_tracker.py`
3. Run in terminal: `python stock_tracker.py`

## Concepts Used
dictionary, input/output, basic arithmetic, file handling
